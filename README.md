# Customer Churn Analysis using R and dplyr

## 📌 Project Description

This project focuses on analyzing customer churn behavior using R, with an emphasis on how **contract type** and **internet service type** influence customer retention. The goal is to identify high-risk customer segments and extract meaningful insights that can help reduce churn.

The analysis is performed using the **dplyr** package for data manipulation and exploratory data analysis.

---

## 📊 Objectives

- Understand tenure patterns of churners vs non-churners  
- Analyze churn across different contract types  
- Study the effect of internet service type on churn  
- Identify high-risk customer groups  

---

## 🔍 Key Findings

- **Churners tend to leave early:** Most churn occurs within the first few months of tenure.  
- **Longer contracts lead to better retention:** One-year and two-year contracts show significantly lower churn.  
- **Month-to-month + Fiber Optic is the highest risk group:** This segment has the highest early churn.  
- **DSL generally shows lower churn** compared to Fiber Optic within the same contract type.  

---

## 🛠 Tools & Libraries

- Language: R  
- Main Library: `dplyr`  
- Optional: `ggplot2`, `tidyverse`
